# zzl071214.github.io

个人 GitHub Pages 用户站根目录，提供不带仓库名的短网址入口。

- 站点：<https://zzl071214.github.io/>
- 入口页指向：<https://zzl071214.github.io/lst-blessing/>（LST&ZZL 祝福页）

## 为什么需要这个仓库

GitHub Pages 的用户站只有在存在名为 `<用户名>.github.io` 的仓库时才会生效。
没有这个仓库时，访问 `https://zzl071214.github.io/` 会返回 404；
有了它之后，根域名即可访问，适合做短网址入口或以后扩展成个人导航页。

## 修改

直接编辑 `index.html` 即可，推送后 GitHub Pages 会自动重新构建。
